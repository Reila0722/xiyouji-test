### HTML/JS 开发规范
- **中文引号问题**：JavaScript/HTML 中使用中文引号 `""` 会导致语法错误，因为 JS 会把中文引号误识别为字符串结束符。**必须使用 `【】` 或 `『』` 替代中文引号，或在字符串外使用单引号包裹含中文引号的内容。**
- 修复方法：搜索 `"[^"]*"[^"]*"` 模式排查，或将所有中文引号替换为 `【】`
- 测试验证：页面加载后检查浏览器控制台（Console），无报错且显示 "事件绑定完成!" 才算正常

### 工具使用
- Python 启动 HTTP 服务器：`python -m http.server 8888`
- 用浏览器打开本地页面：`start http://localhost:8888/index.html`
